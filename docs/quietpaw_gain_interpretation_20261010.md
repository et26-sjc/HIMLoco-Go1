# E3 结果解释 — 2026-10-10

八组训练及 24 次最终评估完成，自动审计通过。没有任何增益在两个训练
seed 上通过预先规定的预算/性能联合标准。当前未解决噪声约束问题，
不能宣称复现了 QuietPaw 的可控静音或 Pareto frontier。

## 可以确认的结果

1. 低初始学习率显著缓解了先前的热启动破坏。E1 同数据回放定位到高 LR
   下 HIM auxiliary update 引起的策略突变；E2 短程训练验证改善；E3 的
   gain0 最终随机评估存活率分别为 98.14% / 98.38%，tracking error 为
   0.1700 / 0.1735。不能把更稳定的热启动等同于所有更新均稳定。
2. 增益确实进入了约束回路。最终平均 lambda 随 gain 从约 0.01（gain1）
   增至约 1（gain100）和 12.84 / 14.22（gain1000）。保存的逐环境 episode
   成本和 valid 掩码可重放出最终 PID 状态；八组各完成 6000 次 PPO 和
   6000 次 HIM 更新，参数均有限，初始权重及优化器按 seed 配对一致。
3. 更大增益没有在主评估中形成一致的成本下降。预算为 0.037646：

| Gain | Seed4 Jc | Seed5 Jc |
| --- | ---: | ---: |
| 0 | 0.041009 | 0.041251 |
| 1 | 0.040587 | 0.041330 |
| 100 | 0.041454 | 0.040333 |
| 1000 | 0.042175 | 0.042052 |

gain1000 相对 gain0 的 cost 反而升高约 2.84% / 1.94%，tracking error
恶化约 28.3% / 23.9%。所有主评估均超预算，gain100 的小幅收益也没有
在两个训练 seed 中同向重复。这是本次固定 300 轮实验的负结果，不能
据此证明预算不可行或任何更长训练都无效。

## 梯度诊断支持什么、不支持什么

第 299 轮三个预定 rollout 时间块上，gain1000 的 actor 成本/奖励梯度
范数比为 seed4 约 5.2%–7.3%、seed5 约 3.4%–10.4%。gain1 对应约
0.009%–0.060%、0.028%–0.032%。因此不能继续简单解释为成本梯度完全
没有进入 actor 或 lambda 根本未更新。

这些是有限样本上的加权 loss 梯度分解，非完整 Adam 参数位移，也不
代表每个训练时刻。它们不能证明 cost advantage 估计准确、约束压力
已经足够或策略能通过当前代理学到期望的物理行为。

## 部署结果与主评估不能混用

gain1000 在固定 (1,0,0)、均值动作、seed11 部署条件下，cost 分别从
gain0 的 0.04049 / 0.04028 降到 0.03421 / 0.03498。但 tracking error
分别从 0.1465 / 0.1425 升至 0.1836 / 0.1886；基座加速度 RMS 从
0.5405 / 0.5375 g 升至 0.5661 / 0.5636 g，hard-force 频率也升高。
不能称为整体静音和性能同时改善。

主评估使用高斯采样、训练指令分布及不同评估设置；部署评估使用均值
动作、固定指令和 200-Hz observer。二者同时改变多个条件。观察到的
差异还不能单独归因于随机动作。

一个需验证的线索：gain1000 的最终动作 std 均值为 0.4643 / 0.4536，
gain0 为 0.3471 / 0.3496。均值动作轨迹可能改善而随机策略成本没有
改善，但这只是待验证假设，不是已定位的因果机制。

## 仍有训练稳定性风险

初始 LR=1e-5 并不约束后续 adaptive LR，其最高值达到约
2.6e-4–5.8e-4。部分更新仍有较大策略漂移：例如 seed4 gain1 的固定
256 条观测探针中，47/300 个更新结束时 KL>0.1。这里的 KL 相对当轮
采集策略，不是每一步变化的累加。初始崩坏已缓解，长期稳定性尚不能
视为完全排除；本轮没有偷偷加入 LR cap。

## 建议的下一次诊断

先使用现有 checkpoint 做固定评估，无需立即再训：在相同 seed、
commands、terrain、randomization、episode 时钟及 observer 配置下，
仅改变均值动作/高斯采样，对比 gain0 与 gain1000。再独立改变指令
分布，区分动作随机性与任务分布的影响。报告 cost、每存活时间 cost、
tracking、存活、触地和物理冲击；不把确定性部署成功当作随机 CMDP
约束已经满足。

后续训练若针对更新漂移，则将 LR cap 作为独立参数对照，保持 cost、
epsilon、PID 和 HIM auxiliary objective 不变；不与新 cost 或 Stage2
同时引入。当前不支持单凭此轮结果继续盲目增大增益。
