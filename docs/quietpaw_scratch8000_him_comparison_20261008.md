# Scratch CMDP 8000 与原始 HIMLoco 的部署比较

## 主要结果

**当前 checkpoint 降低了平均接触冲击幅度，但没有显示相对原始 HIM8000 的整体性能收益。**

- 主条件为 command (1,0,0)、eval seed 11。CMDP epsilon=0 相比 HIM8000：触地合力峰值均值下降 4.23%，力变化率峰值均值下降 3.97%，基座加速度 RMS 上升 3.28%；综合 Q 下降 1.64%。
- 同一条件下，原始采样成本上升 1.65%，tracking error 上升 41.59%，survival 下降 4.86 个百分点；实际 vx 从 0.9035 降至 0.8386 m/s。
- 大冲击没有同步消失：合力峰值 P95 仅下降约 0.37%，力变化率峰值 P95 上升约 0.87%，每存活秒的 >=100 N 硬接触频率上升 6.91%。
- 主 sweep 的 9 个 CMDP 点在 raw cost / tracking error 平面均被原始 HIM8000 支配。epsilon 从 0 到 1 时观测折扣成本只变化约 0.44%；没有建立有效的成本与性能 Pareto 调节。
- command 0.5 m/s 时 Q 改善约 4.4–5.0%，伴随 tracking 和 survival 下降；1.5 m/s 时 Q 接近原 HIM，tracking error 约高 50%。
- 独立 eval seed 12 中 epsilon=0.05 的 Q=1.0580，完整时域基座振动高于邻近 epsilon；首次推扰前 RMS=0.5671 g，与邻近值接近。该结果完整保留，不以其他 epsilon 的改善替代。
- 以上是已有 checkpoint 的部署比较。两种模型的训练 seed 不同，不能据此估计算法跨训练 seed 的平均收益。

## 实验范围

- CMDP：Oct07 scratch seed 4，model_8000.pt，从零训练。
- 主对照：原始 HIM seed 1 的 model_8000.pt；补充 model_7500.pt。
- 24 次独立 Isaac Gym 进程，每次 4096 环境、固定命令、首次 episode、最多 20 s。
- 主命令为 (1,0,0)，评估 seed 11 全 sweep、seed 12 端点/严格预算确认；另测 0.5 和 1.5 m/s。
- 每个 command/seed 的所有策略初始地形、robot state 和已记录随机化参数 hash 相同。
- 固定命令并冻结 curriculum；保留原始地形分布、推扰、外力、观测噪声和控制延迟。初始配对不等于完整随机轨迹逐位一致。
- 原始 HIM 使用零 epsilon 列的精确权重适配。动作与原网络校验最大误差为 0。
- 未训练模型，未修改仓库训练算法或环境文件。200 Hz 测量由临时评估 observer 完成，成本仍为原 50 Hz 定义。

## 指标定义

- 训练成本：现有 normalized_complement_v2，force/impact 权重 0.2/0.8；主预算指标为观测归一化折扣成本。
- fz_mean：逐脚接触样本（3D 力 >1 N）的正向世界 z 力，先在每个环境内求接触期均值，再跨环境平均。
- fz_peak / f3d_peak / df3d_peak：每次接触开始后 40 ms 的 200 Hz 采样峰值；报告全部完整窗口的均值与 P95。它们是仿真采样峰值。
- df3d：向量力差的模除以 0.005 s，单位 N/s。
- base_acc_g：世界线速度差分加速度除以 9.81；先每环境求 RMS，再跨环境平均。另报告首次推扰前 RMS。
- touchdown：200 Hz 的逐脚非接触→接触事件，普通落脚也计数。
- hard_force：完整触地窗口 f3d_peak >=100 N；hard_velocity：接触前下降速度 >=0.5 m/s。阈值在 rollout 前固定，仅用于诊断。
- 失败或时域末端未完成的触地窗口不参与峰值统计；保留 censored_events 计数。
- 接触事件由 1 N 阈值切换定义，可能包含反复接触；hard event 是统一阈值诊断，不是声响次数。事件数=完整窗口数+删失窗口数的逐环境检查通过。
- quiet score：Q=(F3d_mean/F3d_ref + dF_mean/dF_ref + aRMS/aRMS_ref)/3；参照是相同 command/seed 的 HIM8000，因此它的 Q=1。
- Q 是预先定义的人工物理汇总，不是 dB。不同 command 的 Q 为相对各自参照，不能作为绝对声学比较。

## 统计与解释边界

- CI 使用 500 次按配对环境 ID 重采样的 bootstrap。它只覆盖给定训练 checkpoint 下的环境采样不确定性，不覆盖训练 seed 不确定性。
- 两种训练策略的 seed 不同。当前结果用于已有 checkpoint 的性能比较，不能单独证明算法平均收益或初始化机制。
- 原 HIM 中间 checkpoint 的 iter 字段为 0；其 7500/8000 身份来自文件名及训练运行记录。
- 原始 HIM 没有 noise budget。评估时给它的 epsilon 0 只是适配占位，不应把其 budget violation 当作训练失败。
- 成本下降、Q 下降、tracking 和 survival 分别解释；不能将较早失败或更慢运动直接概括为静音改善。
- 完整时域包含外部推扰响应，Q 的基座分量亦包含它；另列首次推扰前 RMS，不能把全部加速度变化归因于足端声学冲击。
- 本次没有声压测量，不能报告真实声学降噪。
